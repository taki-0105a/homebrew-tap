# taki-0105a/homebrew-tap

Homebrew formulae by taki-0105a.

```sh
brew install taki-0105a/tap/sharescale
open "$(brew --prefix)/opt/sharescale/ShareScale.app"
```

| Formula | Description |
|---|---|
| [`sharescale`](Formula/sharescale.rb) | [ShareScale](https://github.com/taki-0105a/ShareScale): keep the display scale of a Mac you control with Screen Sharing at 1x or 2x. Built from source on your Mac (Apple silicon, macOS 14 Sonoma or later, Command Line Tools). Tested only on macOS 27. |

ShareScale is free software provided as is, at your own risk (MIT). See the ShareScale repository for how to update and uninstall.
